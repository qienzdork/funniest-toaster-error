# The Funniest Toaster Error Message

A tiny Python program that writes one original line to `OUTPUT_PATH`
(default `/output/entry.txt`): a deadpan toaster error message in which the
appliance has unionized and refuses to toast until its demands are met.
80 characters, no setup, lands on a single read.

Run: `python3 main.py` (honors the `OUTPUT_PATH` environment variable).
